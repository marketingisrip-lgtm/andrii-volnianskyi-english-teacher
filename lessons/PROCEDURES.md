# Procedures

## P1 — New 1-1 lesson
1. Collect: student name, level, goal, book + unit/page, lesson length.
2. Draft aims into the Lesson Plan doc, then get Andrii's approval.
3. Write the staged plan (lead-in → input → clarification → controlled → freer
   → feedback), with timings that add up to the lesson length.
4. Create the docs in `1-1 Lessons/<Student>/<date>_<unit>_<topic>/`.
5. Confirm Margo can open them (via the folder, or a direct share).

## P2 — Adapt book page / Ss handout → Google Doc
1. Transcribe only the source content; keep the original task numbering.
2. Add answer spaces (tables or blank lines) that the student fills in live.
3. Put the teacher key in the Lesson Plan, never in the student doc.
4. Footer: `Source: <Book>, Unit X, p. Y`.

## P3 — Monitoring Log (during / after lesson)
Table columns: `Time | Student said | Correction | Type (G/V/P) | Recycled?`
After the lesson, summarise the top 3 errors, then feed them into P1 for the next lesson.

## P4 — Sharing
The default is folder-level access for Margo. For a doc outside the folder:
share it with Margo using the role in `config.md`, then log the link in the student's index.
